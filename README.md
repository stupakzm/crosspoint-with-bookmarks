# CrossPoint Reader — with Bookmarks

A fork of [crosspoint-reader/crosspoint-reader](https://github.com/crosspoint-reader/crosspoint-reader) that adds multi-bookmark support to the EPUB reader.

For full device setup, flashing instructions, build prerequisites, and all original features see the [upstream README](https://github.com/crosspoint-reader/crosspoint-reader#readme).

---

## What's new: Bookmarks

The original firmware remembers your last reading position per book. This fork extends that with named, persistent bookmarks — you can save as many positions as you like per book, browse them as a list, preview any bookmarked page, jump to it, or delete it.

### Adding a bookmark

Open the reader menu (press **Select** while reading). The top two items are now:

| Item | Behaviour |
|------|-----------|
| **Add Bookmark** | Saves the current page as a bookmark. |
| **Bookmarks** | Opens the bookmark list for this book. |

If a bookmark already exists at the current page, **Add Bookmark** is replaced by the bookmark's name (dimmed, non-interactive) so you can see at a glance that this page is already saved.

### Bookmark names

Bookmarks are named automatically:

```
Bookmark-{N}-Chapter {C}-{page}/{total}
```

- `N` — position in book order (1-based), re-calculated after any removal
- `C` — spine chapter index (1-based)
- `page/total` — page number within that chapter

Example: `Bookmark-2-Chapter 5-146/345`

The list is always sorted by book structure (chapter first, then page), so bookmarks stay in reading order regardless of when they were added.

### Bookmark list

Selecting **Bookmarks** opens a scrollable list of all saved bookmarks for the current book. If no bookmarks have been saved yet, the screen shows *"No bookmarks saved"*.

Navigate with **Prev**/**Next**, press **Select** to open a bookmark's preview, press **Back** to return to the reader.

### Bookmark preview

Selecting a bookmark from the list opens a full-screen preview of the bookmarked page — the page is rendered exactly as it appears during reading, using the current font, margins, and orientation settings.

**Overlay hidden (default):**

| Button | Action |
|--------|--------|
| Prev / Next | Navigate between bookmarks (page re-renders) |
| Select | Show overlay |
| Back | Return to bookmark list |

**Overlay visible:**

| Button | Action |
|--------|--------|
| Prev / Next | Cycle through the three overlay options |
| Select | Activate the highlighted option |
| Back | Return to bookmark list |

The three overlay options are:

| Option | Effect |
|--------|--------|
| **Hide overlay** | Dismiss the overlay, return to full-page view |
| **Go to position** | Jump the reader to this page (saves it as the current reading position), closes the bookmark list and returns to reading |
| **Remove** | Delete this bookmark; if other bookmarks remain the next one is shown; if the list is now empty the bookmark list screen is shown |

The overlay respects the user's chosen screen orientation (portrait, landscape CW/CCW, inverted) — it rotates with the rest of the UI.

### Storage

Bookmarks are stored per-book in the existing `.crosspoint` cache directory on the SD card:

```
.crosspoint/
└── epub_<hash>/
    ├── progress.bin     # last reading position (unchanged)
    ├── bookmarks.json   # bookmark list (new)
    └── ...
```

`bookmarks.json` is a JSON array. Each entry stores the spine index, page number, and page count — the display name is derived at runtime.

```json
[
  {"s": 4, "p": 145, "c": 344},
  {"s": 7, "p": 22,  "c": 198}
]
```

Deleting `.crosspoint` (or using *Delete Book Cache* in the reader menu) also removes all bookmarks for that book.
